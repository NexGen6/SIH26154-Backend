# SIH2026 PS 154 Backend | [ NextGen6 ]

This repository contains the backend service for our **Smart India Hackathon (SIH) 2026** project. The backend is built using **Node.js** and **Express**, designed to provide scalable and efficient API endpoints for our solution.

Current Status: **Basic Express Server Setup**

## Tech Stack

* **Runtime:** Node.js
* **Framework:** Express.js
* **Language:** JavaScript (ES6+)

---

## Getting Started

Follow these steps to set up and run the backend server locally.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd SIH26154-Backend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

### Running the Server

* **Development Mode (with auto-reload):**
  ```bash
  npm run dev
  ```

* **Production Mode:**
  ```bash
  npm start
  ```

Once started, the server will be running at `http://localhost:5000` (or your configured PORT).
